プライバシーポリシー

最終更新：2026年11月2日

本方針は、「まると ぴこの あそびじかん」の運営者が使用するアプリ「まるぴこ」と、本ウェブサイトでの情報の取り扱いについて定めます。まるぴこはYouTube API Servicesを利用して、運営者自身のチャンネルへの動画投稿と公開予定の管理を行います。

1. Google・YouTubeから取得する情報

  • Googleとの連携と、その継続に必要な認証情報。
  • 連携したYouTubeチャンネルのID・名称。
  • 投稿した動画のID・URL・タイトル・説明文・タグ・処理状況・公開状況・公開予定日時・子ども向け設定。

Googleアカウントのパスワード、視聴者のアカウント情報、GmailやGoogle Driveの内容は取得しません。

2. 利用目的と権限

取得した情報は、投稿先の確認、動画の投稿、公開予約、投稿状況の確認、重複投稿の防止、Googleとの連携の維持、問題が起きた際の対応に使用します。

連携には youtube.force-ssl の権限を使用します。この権限はGoogle上で動画・評価・コメントの管理を含みます。まるぴこで利用する機能は、チャンネルと動画の情報取得、動画投稿、タイトルなどの登録、公開予約です。

Google APIから取得したデータを販売、広告配信、信用評価、汎用AIモデルの学習に使用しません。

3. 保存場所と保護

認証情報、投稿予定、投稿履歴、動作記録は運営者の端末内に保存し、端末の保護機能やアクセス制限を用いて管理します。認証情報は投稿履歴とは分けて保存します。

認証情報や投稿履歴が本ウェブサイトに掲載されることはありません。

4. 外部への送信

動画、タイトルや説明文、認証に必要な情報をGoogle・YouTubeへ送信します。運営者が外部への通知を有効にした場合は、指定された通知先へ、認証情報を含まない動作エラーの概要を送信します。

Google APIから受領した情報の利用・転送には、Limited Use要件を含むGoogle API Services User Data Policyを適用します。Google・YouTube自身によるデータの取り扱いはGoogleプライバシーポリシーをご確認ください。

5. 保存期間・アクセス解除・削除

端末に保存した認証情報や投稿履歴は、運営者が削除するまで保持されます。削除は運営者が手動で行います。アプリの停止やGoogleとの連携解除だけで、端末上の情報が自動的に消去されることはありません。

  • 連携の解除：Googleアカウントの接続管理で「まるぴこ」へのアクセス許可を取り消せます。
  • 保存情報の削除：アプリの実行を停止したうえで、運営者が端末内の認証情報、投稿履歴、動作記録とバックアップを削除します。削除についてのご相談は、下記のお問い合わせ先で受け付けます。

YouTube上の動画や公開予約の変更・削除は、YouTube Studioで行ってください。アプリとの連携解除や端末内の情報の削除は、YouTube上の動画や公開予約には反映されません。

6. この説明サイトについて

本ウェブサイトでは、アクセス解析ツール、広告、独自の追跡Cookieを使用していません。配信サービスであるGitHub Pagesは、セキュリティ目的でアクセス元IPアドレス等を記録します。詳細はGitHubのプライバシーステートメントをご確認ください。

7. お子さまの情報

まるぴこは成人のチャンネル運営者が利用します。視聴者のお子さまにアカウントの連携や情報の入力を求めることはありません。

8. 変更とお問い合わせ

情報の取り扱いに変更がある場合は本ページを更新します。
