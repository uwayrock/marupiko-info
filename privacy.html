プライバシーポリシー

最終更新：2026年10月31日

本方針は、「まると ぴこの あそびじかん」の運営者が使用する個人用動画投稿ツール「まるぴこ」と、その説明サイトに適用します。一般ユーザーのアカウントを預かるサービスではありません。

1. Google・YouTubeから取得する情報

  • Google OAuth 2.0のアクセストークン、更新トークン、有効期限、許可された権限。
  • 認証した運営者のYouTubeチャンネルID・チャンネル名。
  • 投稿した動画のID・URL・メタデータ・処理状態・公開状態・公開予約日時・子ども向け設定など、投稿管理に必要な情報。

Googleアカウントのパスワードは取得・保存しません。Gmail、Google Drive、連絡先、視聴者のアカウント情報、コメント本文の取得機能はありません。

2. 利用目的と権限

取得情報は、投稿先チャンネルの確認、動画アップロード、タイトル・説明文・タグ等の登録、公開予約、処理状況の確認、重複投稿防止、認証更新、エラー対応に使用します。

使用する権限は https://www.googleapis.com/auth/youtube.force-ssl です。Google側では動画・評価・コメント等の管理を許可する権限ですが、現行実装が行うのは上記の投稿管理操作です。Google APIから取得したデータを広告配信、販売、信用評価、汎用AIモデルの学習に使用しません。

3. 保存場所と保護

認証情報、アップロード再開用情報、投稿キュー、投稿履歴、運用ログは、運営者のPCに保存します。トークンは一般の投稿履歴や通常ログから分離します。Windowsネイティブ環境ではユーザー単位のDPAPI保護、WSL/Linuxでは所有者に限定したファイルアクセス権を使用します。後者はディスク暗号化を意味しません。

この説明サイトへ認証情報や投稿履歴をアップロードする処理はありません。

4. 外部への送信

動画ファイルとメタデータ、認証に必要な情報をGoogle・YouTubeへ送信します。運営者がWebhook通知を設定した場合に限り、その指定先へ秘密情報を除いたエラー要約等を送ります。この設定は任意です。

Google APIから受領した情報の利用・転送には、Limited Use要件を含むGoogle API Services User Data Policyを適用します。Google・YouTube自身によるデータの取り扱いはGoogleプライバシーポリシーをご確認ください。

5. 保存期間・アクセス解除・削除

認証情報と投稿履歴は、運営者による利用と投稿管理に必要な間、PCに保持されます。現在の実装には期間による自動削除機能がありません。停止や認証解除だけでローカルの履歴が自動消去されることもありません。

  1. 今後の送信を止めるには、運営者が投稿ツールの自動実行を停止します。
  2. APIへのアクセスは、Googleアカウントの接続管理で「まるぴこ」への許可を取り消せます。
  3. PC上の情報の削除は、ツール停止後に運営者が認証保存領域・関連する投稿履歴やログ・バックアップを確認し、手動で行います。削除方法の問い合わせは下記窓口で受け付けます。

認証を解除したりPCの情報を消したりしても、YouTube上の動画や設定済み公開予約は削除・取消されません。必要な変更はYouTube Studioで別途行ってください。投稿履歴を消して運転を再開すると重複防止に影響するため、削除後にそのまま再開しないでください。

6. この説明サイトについて

このサイトにはログイン、入力フォーム、アクセス解析スクリプト、広告、独自の追跡Cookieを設置していません。ホスティング先のGitHub Pagesはセキュリティ目的でアクセス元IPアドレス等を記録します。詳細はGitHubのプライバシーステートメントをご確認ください。

7. お子さまの情報

制作動画は3歳前後を想定していますが、本ツールを利用・認証するのは成人のチャンネル運営者です。お子さまにアカウント登録や情報入力を求めず、視聴者のお子さまの個人情報を取得する機能はありません。

8. 変更とお問い合わせ

データの取り扱いを変更する場合は本ページを更新し、必要な場合は新たな取り扱いを始める前に同意を確認します。
