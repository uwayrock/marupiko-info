1. 対象と目的

「まるぴこ」は、「まると ぴこの あそびじかん」の成人の運営者が、自ら管理するYouTubeチャンネルへの動画投稿と公開予定を管理するためのアプリです。

2. YouTubeとの連携

まるぴこはYouTube API Servicesを使用します。まるぴこを利用することにより、利用者はYouTube利用規約に同意するものとします。まるぴこはチャンネル運営者が提供するアプリであり、GoogleまたはYouTubeの公式製品ではありません。

3. 投稿内容と公開設定

運営者は、投稿する動画・音声・画像等を使用する権利、タイトルや説明文の内容、子ども向け設定、公開日時を確認して利用します。アプリは運営者の設定に従って動画を投稿し、公開を予約します。

YouTubeに登録済みの動画や公開予約の変更・削除は、YouTube Studioで行ってください。アプリを停止しても、設定済みの公開予約は残ります。

4. データと認証

Googleとの連携は、運営者本人によるアクセス許可に基づいて行います。認証情報の共有や第三者アカウントの無断操作は行わないでください。情報の取得・利用・保存・連携解除・削除については、プライバシーポリシーをご確認ください。

5. 利用上の制限

通信障害、端末の稼働状況、YouTube側の利用制限や処理時間により、投稿や予定どおりの公開ができない場合があります。投稿結果や公開状況は、YouTube Studioでも確認できます。

6. 変更・お問い合わせ

機能や運用を変更する場合は、必要に応じて本ページを更新します。
